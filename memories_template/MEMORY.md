# Hermes Agent - Persistent Memory

- User menggunakan Obsidian sebagai pusat persistent memory agent.
- Vault berlokasi di folder konfigurasi `OBSIDIAN_VAULT_PATH`.
- Bot Discord dikonfigurasi responsif (bebas mention / free response channels).
- Gunakan file ini untuk menyimpan ringkasan preferensi jangka panjang, tugas berkelanjutan, dan konteks penting.
